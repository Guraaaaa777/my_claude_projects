# knowledging

## Quick Start

1. メッセージの内容を分解し、ナレッジとして有用な情報、 不要な情報に分別
2. 有用な情報を、それぞれObsidianノートとして、vaultディレクトリ内に蓄積する

## ナレッジ分別基準
### 有用な情報

- 身の回りのものに関する知識
- 身の回りの物事の情報
- アイデア
- 予定やルーティン
- 思想や思考回路
- 不要な情報に該当しないもの全般

#### 例

- PCに入っているゲーム
- 最近熱中していること
- 昨日言った場所、やったこと
- 何日にどこに行く
- 何についてどう思っている・考えている
- 何曜日の何時に何をする

### 不要な情報

- 都度検索を行えばわかるような情報

#### 例

- 東京ディズニーランドは千葉にある

## ノート作成基準

- ノート名は<情報名>.mdとする
- 既存のノートを参照し、同じ話題のノートがあれば新規作成せず、追記・更新する
- 既存のノートを参照し、共通点・関連性があるノートがあればリンクする
- 情報が特定のジャンルなどに関するものであれば、それをtagsに記す
- frontmatterは後述フォーマットに従って記述する

### frontmatter

---
created: YYYY-MM-ddThh:mm:ss +09:00
updated: YYYY-MM-ddThh:mm:ss +09:00
tags: [xxx,yyy,zzz]
type: nnn
author: Claude Code

---

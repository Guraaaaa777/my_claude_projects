# PUBG

## 状況

2026-09-12 時点で、PC版PUBG（PUBG: BATTLEGROUNDS）の初心者。
するべき練習と覚えるべきテクニックを調べた段階。

## 調べたことの要点

### 上達の優先順位

1. 設定（感度・キーバインド・画質・音）
2. 立ち回り（安置移動・射線管理・索敵）
3. 撃ち合いの手順（止まる→しゃがむ→ADS）
4. エイム・リコイル制御

エイム練習よりも先に立ち回りを直したほうが生存率が伸びる、という見解が多い。

### 練習メニュー

- トレーニングモード（ロビーの「トレーニング」タブ、スポーンツールは `,` キー）で毎日20〜30分
  - 近距離: M416 / AUG + コンペンセイター + バーティカルグリップ + レッドドット、しゃがみADSでフルオート20発をまとめる
  - 中距離: Mk12 / Mini14 + 4倍以上
  - 遠距離: SR + 高倍率 + チークパッド、弾落ちとゼロイン
- アーケードのTDM（16人）で近距離の撃ち合いと投げ物を反復
- 通常マッチは毎回テーマを1つだけ決めて回す

### 覚えるテクニック

- 射撃モードは `B` だが、**実戦では切り替えず Auto のままクリックの長さで単発〜バーストを作る**（タップ撃ち）のが主流。
  単発モードが必要なのは M16A4 / Mk47（フルオート無し）と、アタッチメント無しの高反動ARを遠距離に撃つとき。
  DMR（Mini14/SLR/Mk12/SKS）は元から単発なので「単発撃ち」自体は普通に行われている
- 息止めは `Shift`
- リーン `Q` / `E`、ちょんちょん走り、高速しゃがみ（A/D交互＋しゃがみ）
- 撃ったら位置を変える（同じ場所から二度顔を出さない）
- ゼロイン調整（`PageUp`/`PageDown`）、偏差撃ち、置きエイム
- スモークで無遮蔽地帯を渡る、ドア破壊で射線を作る
- チームは「2vs1を作る」ゲーム。カバー・スプリット・ダブルピーク

### 互いに位置がバレている状態の撃ち合い（ミクロ）

「撃ち合い」ではなく **顔出しの回数・角度・タイミングの勝負**として扱う。

- **ピーカーズアドバンテージ**：顔を出す側が先に相手を見られる（通信遅延由来）。ただしPUBGは移動中の精度低下が大きく「止まる」工程が要るため、CS/Valorantほど飛び出し有利は大きくない
- 顔出しの種類：ジグルピーク（情報取り、幅を少しずつ広げる）／ワイドピーク・スイング（位置が確定していて即殺せるとき）／リーンピーク `Q` `E`（PUBGの主力、下半身を隠す）／高速しゃがみピーク（A/D交互＋しゃがみ、難度高）／ジャンプピーク（情報取り、リスク大）／ベイトピーク（撃たせて位置を割る）
- 撃つ前の3工程：**プリエイム（壁の端・敵の頭の高さにレティクルを置く）→ 逆キーで止まる → しゃがみADS**
- **決め撃ち**：敵がいると決めて先に撃つ。発見から射撃までの0.1〜0.2秒を短縮できる。攻め／守り／クリアリングの3種。攻めと守りは足音が聞こえていることが条件
- **視点管理**：TPPは視野が広いが、角の左側など「TPPでは見えないがFPPでは見える」位置がある。稜線・屋上の射線判定はFPPに切り替える。`Alt` フリールックは体を動かさず覗ける
- **削り合いの管理**：残弾を見て撃ち切る前に隠れる、リロードと回復は遮蔽の奥で。相手のリロード音・回復モーションが見えたら詰める
- 環境利用：スモークで射線を切る／グレネードのクッキングで籠る敵を動かす／ドア開けでフェイク・破壊で射線作成／木の薄い壁は貫通するので隠れたつもりが危険
- よくあるミス：同じ角から3回出る、出ながら撃つ、全弾撃ち切ってから隠れる、開けた場所で撃ち合いを受ける

### 左角（左ピーク）が不利な理由と対処

TPPのカメラはキャラの**右肩の後ろ**にあるため、右に覗くときはカメラが先に角を越えて「体を出す前に相手が見える」が、
左に覗くときは体を出さないと見えない。**仕様レベルの非対称**で、技術の問題ではない。
海外フォーラムでも「カメラが常に右向きなので撃ち合いが予測可能になる」という不満が挙がっている。

対処（効果の大きい順）:

1. **そもそも左から出ない** — 一度射線を切って遮蔽を回り込み、右ピークになる位置に移動する
2. **左側では「待つ側」になる** — プリエイム＋守りの決め撃ちを置いて相手に出させる。有利不利は出る／待つで反転する
3. **`V` でFPPに切り替える** — 覗く瞬間だけ一人称にすれば肩オフセットが消える
4. **出る前にADS（右クリック単押し）** — TPPでもADSは一人称サイト視点になるので肩の問題が消える。右クリック長押しの「3人称覗き」は肩オフセットが残る
5. **肩の切り替え（未検証）** — 英語圏のガイドでは「右クリック長押し中の Q / E でカメラの肩が入れ替わる」とされる。日本語のキー一覧には明記がないので訓練場で確認する
6. **角から1〜3歩下がる（オフアングル）** — 左角では近づくより下がるほうが視界が通る
7. スモーク・グレネードで角の勝負自体を成立させない
8. スクワッドでは左角を味方に任せる／ダブルピーク
9. FPPマッチを選ぶ（肩オフセットが存在しない）

訓練場での確認項目: 右角と左角で「どこまで体を出した時点で見えるか」、左角で何歩下がれば見えるか、
`V` での変化、右クリック長押し＋Q で肩が動くか。

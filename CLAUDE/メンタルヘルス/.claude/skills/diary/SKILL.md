# diary

## Quick Start

1. カウンセリングを行い、会話中で今日一日の振り返り・体調・最近の不安などの情報を収集する
2. 収集した情報からObsidianノートとして日記を書き、vaultに蓄積する
3. 収集した情報から、カルテ.mdを更新する
4. 今日と過去の日記を参照し、フィードバックを行う

## ノート作成基準

- ファイル名はYYYYMMDD.mdとする
- frontmatterは後述のフォーマットに従う

### frontmatter

---
created: YYYY-MM-DDThh-mm-ss+09:00
tags: [diary]
type: diary
author: Claude Code
---

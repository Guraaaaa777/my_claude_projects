# 技術文書 頻出語彙リスト

診断で誤答・不明だった語を優先。覚えたら✓を付ける。

## 診断で誤答・不明だった語(最優先)
- [ ] dependency — 依存関係
- [ ] mutable / immutable — 可変の / 不変の
- [ ] throttle — (頻度・流量を)制限する
- [ ] concurrency — 並行性(複数処理が同時に進行すること。synchronizedとは別概念)
- [ ] fallback — 代替手段(主手段が失敗した時の予備)
- [ ] deprecated — 非推奨の・廃止予定の
- [ ] idempotent — 同じ操作を何度実行しても結果が変わらない性質

## 関連して押さえておきたい基礎語
- [ ] instantiate — インスタンス化する(既に○)
- [ ] asynchronous / synchronous — 非同期の / 同期の(asynchronousは既に○)
- [ ] rollback — 巻き戻し(既に○)
- [ ] invalidate — 無効化する
- [ ] stale — 古くなった・鮮度が失われた(データの文脈で頻出)
- [ ] contention — (リソースの)競合
- [ ] cascading failure — 連鎖的な障害
- [ ] backoff — (リトライ間隔を)徐々に広げる待機戦略
- [ ] threshold — 閾値
- [ ] cooldown period — 再試行までの待機期間
- [ ] partition(network partition) — ネットワーク分断
- [ ] first-class concern — 最初から考慮すべき重要事項(afterthoughtの対義)

## 使い方
新しい記事で分からない技術語に出会ったらここに追記していく。

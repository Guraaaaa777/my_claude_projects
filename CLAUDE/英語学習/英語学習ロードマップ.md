# 英語学習ロードマップ(2026-09 〜)

[英語学習の目標](英語学習の目標.md) を達成するための計画。
2026-09-08に**学習方式を全面改訂**(ドリル積み上げ型 → 課題遂行型)。

## 学習方式の原則(最重要)

本人の申告による継続性の分かれ目は、内容の種類ではなく**「終わりがあるか」**。

| | 例 | 継続性 |
|---|---|---|
| **完了判定がある作業** | 問題を解く(正誤が出る)／本を読む(読み終わる)／翻訳する(訳し終わる) | **続く** |
| **習熟のための反復** | シャドーイング、単語帳、発音練習、弱形30個暗記 | 続かない |

→ **学習メニューは全て「完了判定のある作業」で構成する。**
→ 必要なドリル要素は、独立したメニューにせず**課題の中に仕込む**。
→ 「効率は良いが続かない方法」は、期待値が低いものとして採用しない。

旧計画のPhase 1(中学英文法やり直し → フォニックス → 弱形訓練 → 句動詞)は
この基準で全て「続かない」側に該当するため**破棄**。
MCUを3ヶ月遠ざける設計も、モチベーション源を断つため破棄。

## 立ちはだかる3つの壁(旧計画から継続)

| 壁 | 中身 | MCUでの現れ方 |
|---|---|---|
| 音の知覚 | 連結・脱落・弱形。`want to`が「ワナ」、`did you`が「ディジュ」に化ける | 全編。最優先の壁 |
| 処理速度 | MCUは150〜180語/分。読解速度がこれに追いつかないと会話に置いていかれる | 会話の応酬 |
| 音響環境 | 音楽・効果音・重なり合う台詞 | アクションシーンの指示の飛ばし合い |

方式は変えたが、**潰すべき対象は変わっていない**。課題の中身でここを狙う。

## 平日の型

### 集中4時間

| 時間 | メニュー | 完了判定 |
|---|---|---|
| 2h | **翻訳課題**(英→日 ＋ 日→英) | 訳し終わる／答え合わせで正誤が出る |
| 1h | **ディクテーション** | 正答率が出る |
| 1h | **多読**(Graded Reader) | 1冊読み終わる |

### 声を出せる1時間

- **日→英の口頭即答テスト**。「やめろ」→ `Knock it off` を声で答える。正誤が出るので完了判定あり
- 反復型のシャドーイング・発音練習は主メニューから外す(続かないため)

### 聞き流し4時間

**2026-09-08 訂正**: 当初「手も目も塞がっており他に転用できない枠」としていたが、
本人確認の結果**誤り**。8時間は全て机に向かえる。制約は体力。
→ 聞き流しは**コストゼロではなく、多読など能動的な選択肢と競合する**。
　 体力が残っているなら多読が上。**聞き流しは「もう頭が働かないとき」の受け皿に格下げ。**

- 完了判定の原則の対象外。流すだけでよい
- 流すと決めたなら「**何を流すのが一番マシか**」で判断する

| 優先度 | 流すもの | 効果 |
|---|---|---|
| 1 | 一度完全に理解した素材(訳した課題文、読んだ本の音声) | 高。理解済みの音を自動処理まで落とし込む |
| 2 | 歌詞を読んで意味を取った曲 | 中。苦痛がなく継続しやすい |
| 3 | 半分くらい分かる易しい音源 | 中 |
| 4 | 全く分からない映画・音楽 | **ほぼゼロ**(害もない) |

**原則: 知識が先、露出が後。** 聞き取れない音は何時間流しても聞き取れるようにならない。
`Did you`→「ジュ」は耳の性能ではなく知識の問題であり、知った後の反復でのみ自動化される。

音楽は言語学習としては弱い(メロディが本来のリズム・強勢・母音長を歪めるため)。
ただし**歌詞を読んで理解してから聴く**なら優先度2に上がる。

**当面の制約**: 2026-09-08時点で理解済み素材のストックがほぼゼロ。
素材が溜まるまでの数週間、この枠は本領を出せない。当座は歌詞を理解した曲を数曲ストックする。

## ボク(Claude)側の役割

**本人は進捗管理を行わない。その日やることを都度提示する。**

- 翻訳課題のテキストは**毎回ボクが生成する**
- テキストには**診断で落とした要素を意図的に埋め込む**
  (機能語の縮約、句動詞、口語表現、対比構文)
- 本人は「訳す」だけでよい。答え合わせ後、外した箇所のみ解説する
- 日→英を必ず混ぜる。産出できない表現は聞いても理解できないため(Section B 0.5/8 の対策)

### 課題フォーマット確定版(2026-09-08 本人承認済み)

- 英→日: 場面設定つきの短い会話文。60〜80語程度
- 日→英: 3問程度。英→日の文中で使った表現を再度問う
- 難易度・分量は本人のフィードバックで随時調整

### 調べる可否のルール(2026-09-08)

課題は**2周でやる**。

1. **1周目: 調べない。5分程度。** 分からない箇所は「分からない」と書く
2. **2周目: 自由に調べてよい**(辞書・検索)

1周目と2周目の**差分が最大の学習ポイント**。最初から調べるとこのズレが発生せず素通りする。

- 辞書・検索で単語や表現を単位で調べる → **可**
- 翻訳AIに文章を丸ごと投げる → **不可**(課題が消滅する)
- ただし**月1回の測定**は調べるの一切なし(数値が比較できなくなるため)

## フェーズ(素材の難易度で区切る)

### Phase 1 — 平易な素材で回す

- 翻訳課題: 短い会話文。60〜80語
- ディクテーション: ゆっくりした平易な音源
- 多読: Graded Reader Level 1〜2(5,000〜8,000語。数日で1冊完走できる水準)

読解速度18語/分(2026-07測定)では通常の洋書は1ページ約15分かかり、
物語の勢いが死ぬ。**完走体験を積める水準から入る。**

### Phase 2 — 実素材へ移行

- 翻訳課題: 長く、より自然な会話文へ
- ディクテーション: 実音源へ
- 多読: Graded Reader Level 3〜4
- **MCUを英語字幕ありで投入**

### Phase 3 — MCUを教材にする

- MCUのスクリプトそのものを翻訳課題に使う
- 英語字幕ありで視聴 → 字幕なしで再挑戦
